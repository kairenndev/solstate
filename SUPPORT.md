## Worth more than money

**Open an issue** when a metric looks wrong. Data collection breaks quietly and
from the outside — an upstream API changes a field name and the number goes
stale rather than absent. A report that says so is worth more than one that
does not.

**Tell me what is missing.** The metric set here is a judgement call about what
matters. If you track something this does not cover, that is a gap worth
knowing about.
